HOW TO VIEW DEMOS:
1. place demo files AND Map folder(s) in your game's root directory
	csgo: steam\steamapps\common\counter strike: global offensive\csgo [YOU MUST OPT IN TO CSGO LEGACY TO VIEW ON SOURCE]
	dod: steam\steamapps\common\Day of Defeat: Source\dod
	ep2: steam\steamapps\common\Half-Life 2\ep2
	hl2: steam\steamapps\common\Half-Life 2\hl2
	sfm: steam\steamapps\common\source filmmaker\game\usermod
	tf2: steam\steamapps\common\Team Fortress 2\tf

2. Launch the game and enable developer console

3. Open the console (~ key) and type
	PLAYDEMO <DEMONAME>
		for example, opening TEAM FORTRESS 2 and typing "playdemo data21' will play the 21st data file in the tf dump
